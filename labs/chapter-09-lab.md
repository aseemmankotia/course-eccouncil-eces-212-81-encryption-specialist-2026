# Chapter 9 Lab: Wi-Fi Security, VPNs, Disk Encryption, and Steganography

**Estimated time:** 25 minutes

## Exercise

Create an encrypted VeraCrypt container and mount it, enable BitLocker on a test VM volume, then use an LSB steganography tool to hide a text file inside a PNG image and extract it back out

## Key takeaway

Distinguish confidentiality-providing protocols (ESP, WPA3, VeraCrypt) from integrity-only mechanisms (AH, blockchain hashing) — this distinction is a recurring exam trap.
