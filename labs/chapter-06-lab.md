# Chapter 6 Lab: RSA, Diffie-Hellman, DSA, ElGamal, and ECC

**Estimated time:** 25 minutes

## Exercise

Use OpenSSL to generate an RSA-2048 key pair and a matching-strength EC key pair (P-256), then simulate a Diffie-Hellman key exchange between two OpenSSL processes and confirm both sides derive the same shared secret

## Key takeaway

Know which algorithm solves which problem — RSA (factoring), DH/DSA (discrete log), ECC (elliptic curve discrete log) — and memorize the key-size equivalence table.
