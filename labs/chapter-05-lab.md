# Chapter 5 Lab: Number Theory Foundations for Asymmetric Crypto

**Estimated time:** 20 minutes

## Exercise

Write a short Python script that picks two small primes, computes n and φ(n), derives a public/private exponent pair, and performs modular exponentiation to encrypt and decrypt a small number

## Key takeaway

Every asymmetric algorithm rests on one hard math problem — factoring, discrete log, or elliptic curve discrete log — and the exam tests which algorithm relies on which.
