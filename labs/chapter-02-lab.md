# Chapter 2 Lab: Block and Stream Ciphers: DES to AES

**Estimated time:** 20 minutes

## Exercise

Use OpenSSL CLI to encrypt the same file with AES-256-CBC and DES-CBC, compare ciphertext size and command syntax, then time both operations

## Key takeaway

AES has replaced DES/3DES/RC4 in virtually every modern context — know their historical weaknesses because the exam tests why they were deprecated.
